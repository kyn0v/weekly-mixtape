# 网易云客户端下载（已实测）

前提：已登录、有相应下载权限；用户暂不操作桌面。下载目录固定为 `~/Music/网易云音乐`。

1. `open -a NeteaseMusic` 唤起主窗口（仅 activate 在窗口关闭时不一定能恢复）。读取当前窗口位置并截图。左侧“创建的歌单”找到《本周推荐》，打开并核对当前曲目数、顺序、版本；必要时滚动逐页读取。右键“复制链接”可核对歌单 ID，不能因为名称相同就当成固定歌单。
2. 在客户端设置核对下载路径及音质；希望高解析度无损，不擅自选择音效加工/空间音频版本，不购买升级。记录本次是否沿用默认音质、是否实际有对应规格，最终以音频探测为准。
3. 记录下载目录文件名/大小/修改时间。右击《本周推荐》，找到原生菜单的“下载全部”再 AXPress。已下载的项目可能不再显示下载按钮：先核对已下载标记和本地匹配文件，齐全则跳过；缺文件却无按钮时再检查下载管理，不盲目重试菜单。主页面可能没有 AX 子控件，截图定位右键；弹出的原生菜单可以读取 AXTitle，优先按标题定位，别硬编码索引。
4. 已有 VIP 下载权限的说明弹窗可等倒计时后点“知道了”；付款/登录/会员升级/覆盖旧文件时停下询问。下载权限不是外部发布授权。
5. 等待下载完成，核对歌曲旁已下载标记/下载列表，以及指定目录中匹配文件大小不再变化。缺歌、失败、临时文件不能算完成。已下载歌曲可跳过，不重复下载或改变现有文件。

## 工具
编译 `scripts/ax.swift` 后可设置 `AX_BUNDLE=com.netease.163music` 使用同一个 helper：
- `dump '' 1` 找窗口，再 `dump PATH 2` 读原生菜单。
- `rightclickAt X Y` / `clickAt X Y`：坐标必须由当前截图换算成屏幕 points；每次点击会检查目标应用前置，窗口尺寸变化后重新定位。
- `action PATH AXPress`：先核对菜单标题，防止点到相邻的删除歌单。
- 不要把截图像素直接当 points。Retina 截图常为2倍，裁剪图还需加窗口原点。

前置应用后立刻截图；若截图变成 Paseo 或其他应用，说明焦点被抢走，不能沿旧图继续点击。请用户暂停操作再重试。该流程不依赖私有账户接口/凭据。
